# V4 video engine

Motor de edição 9x16 (podcast/entrevista → vídeo com storytelling, legendas e cards no padrão V4).
Usado pela skill `v4-video-storytelling`.

Uso: `python3 v4video.py <passo> <pasta_do_projeto>`
Passos: setup | transcribe | faces | cropcheck | clips | audio | music | overlay | compose | qa | light
